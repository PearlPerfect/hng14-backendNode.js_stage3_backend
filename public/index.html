Auth Endpoints
GET /auth/github
public
Redirect to GitHub OAuth ▼
Description
Opens GitHub's OAuth authorization page. For CLI use, pass code_challenge, code_challenge_method=S256, and port as query params to enable PKCE + local callback server flow. For web, just redirect the browser here directly.
Flow
1. Browser redirects to GitHub
2. User authenticates
3. GitHub redirects to /auth/github/callback
4. Backend issues access + refresh tokens
5. Web: tokens set as HTTP-only cookies
6. CLI: tokens returned to local callback server
